# Shifu 手機研究（2026-11-11）
使用目前 Codex 內建瀏覽器、原登入工作階段，390 × 844 實際點擊；未讀取 Cookie、Token，未儲存個人資料。下列是觀察紀錄，不是複製原站素材或程式。

## 已實際操作
- 首頁：深色底、頂部品牌／搜尋／購物車數字／會員／漢堡；區段錨點導覽，募資、體驗、排行、分類、優惠、立即上課、文章、頁尾。首頁輪播依需求排除。
- 會員按鈕：下拉選單，學習中心、我的課程、我的收藏、訂單紀錄、會員資料、登出。
- 漢堡：dialog 選單與 Close，找課程、找師父、看文章、常見問題、我的課程。
- /course/trial/baking：由首頁卡片點入。手機大封面、介紹／講師錨點、可收合長內容、場次日期、倒數、0 元／原價、姓名／電話／信箱表單、底部固定立即報名。這是場次報名，不能假設一定經過購物車；原站提及 LINE 發連結，V2 明確排除 LINE。
- /cart：現有 0 元課程，商品列、收藏／移除、訂單小計與總額、前往結帳。
- /cart/checkout：會員購買、不可改的會員信箱、姓名、必填電話、付款方式、發票、訂單明細、折扣碼、條款同意、確認購買。實際 0 元仍顯示付款選項；V2 依業主要求移除金流。
- /course/mylessons：會員資訊、橫向會員導覽、搜尋、所有／上課中／等待開課／已完課、課程卡片進度與評價入口。
- 三門現有體驗課分別點擊：均返回我的課程並顯示尚未開始警示；未能觀看播放器。
- /account/mytask：課程篩選、搜尋、筆記頁籤、無筆記空狀態。
- /account/myaccount：姓名、生日、不可改的信箱、國碼與電話、地址、重設密碼與儲存；只讀，不儲存修改。偏好設定在 DOM 中但手機可見頁籤未提供，未繞過隱藏限制。
- /order/orderlist：日期篩選、成立／退款頁籤，訂單資訊與展開明細；現有免費訂單顯示已付款，付款方式仍標信用卡一次付清。

## 尚未驗證，不能聲稱完成
- 新免費訂單送出與完成頁：缺少必填電話，且需使用條款同意；未提交。
- 真正播放器：目前三門已領取課均未開課，不繞過時間或權限。
- 登出／重新登入與未登入領課返回：尚未操作，以免失去目前登入工作階段。
- 其餘分類／講師／文章第二、三層仍待補測。

## V2 與參考的明確差異
原創寰宇品牌與插畫；沒有首頁輪播與 LINE。0 元免審核、付費人工審核；站內通知；新增課程獎銜限制。所有模擬資料使用獨立 localStorage namespace，沒有中央會員或正式訂單寫入。播放器沒有取得正式授權時不得提供 Signed URL 或冒充播放成功。

## 補充操作
- /course/findcourse：實際開啟課程列表，手機有「課程類型」與「課程分類」兩個下拉選單；選自我成長後，課程列表確實更新。卡片顯示封面、講師、價格／原價、時數與人數，底部提供載入更多課程。
