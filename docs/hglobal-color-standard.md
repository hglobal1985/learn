# 寰宇 H-Global1985 生態系：固定配色規範（版本 1.0，2026-11-13）

**適用範圍**：所有寰宇生態系 App（中央會員、寰宇行動大學，以及未來新增的每一個 App）。**一律使用同一組色，不可自行新增、改色或換風格。** 需要例外時，必須由業主明確核准並記錄。

**色彩來源**：寰宇 logo 的五個主色——深綠、橄欖綠、橘、黃、鮭粉。其餘顏色（背景、文字、危險、成功等）是為了可讀性與無障礙而定的中性或功能色，與主色協調。

機器可讀的色值檔：`docs/hglobal-tokens.json`（中央應放在固定網址供各 App 引用）。完整用法（字級、圓角、方框）見中央會員 `docs/design-standard.md`。

## 1. 品牌主色（取自 logo）
| 名稱 | 色碼 | 用途 |
|---|---|---|
| 主綠 | `#0c603c` | 主按鈕、連結、選中、品牌標題 |
| 橄欖綠 | `#486c48` | 輔助強調、頭像漸層 |
| 橘 | `#cc6c0c` | 提醒、未讀點、獎銜方框字 |
| 黃 | `#f2dc27` | 頂端彩條、反光亮點 |
| 鮭粉 | `#f0a884` | 頂端彩條、軌道弧線 |

頂端彩條：`linear-gradient(90deg, #cc6c0c, #f2dc27 55%, #f0a884)`。

## 2. 淺色模式
背景 `#f8f6ef`｜卡片 `#ffffff`｜主要文字 `#1d2a22`｜次要文字 `#5d6b62`｜分隔線 `#e2dfd2`｜淺綠底 `#e7f1ea`｜橘淡底（提醒底）`#fdf0e3`｜警示字 `#a86408`｜危險 `#b3261e`／底 `#fbeae8`｜成功 `#1b7a43`｜主色上的字 `#ffffff`。

## 3. 深色模式（跟隨系統自動切換）
背景 `#121515`｜卡片 `#1c2020`｜主要文字 `#eeefeb`｜次要文字 `#a6adab`｜分隔線 `#343b38`｜主色 `#cee49f`｜淺綠底 `#2c3622`｜橄欖 `#8fae78`｜橘 `#f0a050`｜橘淡底 `#3a2e17`｜警示字 `#f2c063`｜危險 `#f2b8b5`／底 `#3c1e1c`｜成功 `#9bd39e`｜主色上的字 `#172016`。

## 4. 使用規則（所有 App 必須遵守）
1. 所有 App 都要同時支援淺色與深色，**跟隨系統自動切換**，不提供自訂主題。
2. 顏色只能用本規範的色值（或 `hglobal-tokens.json`）；程式裡不要直接寫色碼，集中放在一個 theme／token 檔。
3. 提醒、公告、警示底一律使用「橘淡底＋警示字」（同一種淡黃橘色塊）；不要用藍色或紫色當系統提示色。
4. 主按鈕用主綠；危險操作用危險色；成功用成功色。
5. 圖片與課程封面的底色不受限，但 App 介面本身（背景、卡片、按鈕、文字）必須用本規範。
6. 文字與背景對比至少 4.5:1（大字至少 3:1）；深色模式的品牌色用深色模式色階，不要沿用淺色色碼。
7. **App 圖示**：以主綠為底的圓角方形，奶油色主體圖形，搭配金黃／橘／鮭粉點綴；圖示網址交給中央登記，讓中央的 App 捷徑顯示相同圖示。
8. 任何例外（要用不同顏色）：先問業主，核准後記錄在該 App 的交接文件與中央登記資料。

## 5. 給新 App 開發 AI 的一句話
「配色請完全使用《寰宇生態系固定配色規範 1.0》（hglobal-tokens.json），支援淺色與深色並跟隨系統；不要自創色碼；圖示用綠底圓角方形。」
