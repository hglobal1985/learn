# 給中央會員系統的需求說明：開放「新增職稱詞條」

提出者：寰宇行動大學（hglobal1985/learn）　日期：2026-11-14　（業主已同意由行動大學這邊撰寫此說明，由業主轉交中央維護者）

## 背景
行動大學的課程資料有「主講人／分享者的職稱」欄位。依業主規定，職稱詞庫以中央會員系統為準（`GET /v1/vocab/suggestions?pool=job_title`），行動大學不自行新增詞條。

## 目前的問題
中央只有「查詢建議」，沒有「新增詞條」的功能。管理員輸入了詞庫沒有的職稱（例如新的職務名稱），只能存在行動大學的課程裡，中央詞庫不會增加，其他 App 也看不到。

## 需求
新增一支給「受信任的服務」呼叫的 API，把新職稱加入 `job_title` 詞庫：

- `POST /v1/vocab/suggestions`
- 請求：`{ "pool": "job_title", "value": "區域經理" }`
- 驗證：服務對服務的憑證（與行動大學現有呼叫中央的方式相同），**不使用會員個人登入**。
- 行為：
  - 前後空白去除、長度上限（建議 50 字）、重複（忽略大小寫與全半形）不新增，回傳既有詞條。
  - 回傳 `{ "pool", "value", "created": true|false }`。
  - 只允許 `job_title` 這個詞庫（其他詞庫如中心、獎銜不開放，避免被誤用）。
- 建議：新增的詞條先標為「待核可」，中央管理員核可後才出現在別人的建議清單（避免亂打）。
- 每次新增請記錄稽核（誰、哪個服務、時間）。

## 行動大學這邊的配合（中央完成後才做）
- 管理員在課程設定輸入職稱，儲存時若詞庫沒有，呼叫上述 API 送出新增。
- 中央回應失敗不影響課程儲存（職稱仍存在課程上），下次再補送。

## 不在此需求內
- 不讀寫任何會員個人的職稱資料。
- 不開放中心、獎銜等其他詞庫的新增。
